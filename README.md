# ShatterHer Impact

SHATTERHERLEADERS — MASTER WEBSITE DESIGN & DEVELOPMENT PROMPT



You are a senior product designer, UX architect, UI designer, frontend engineer, and full-stack product developer.



Create a production-ready web application called “ShatterHerLeaders” for the ShatterHer organization.



This is NOT a generic leaderboard template.



This should feel like a real, modern, purpose-built platform where ShatterHer members can:



- Track their contributions

- Share completed work and contributions

- Earn points

- See their ranking

- View their contribution history

- Understand the point system

- Celebrate their progress

- Stay connected with the wider ShatterHer team



The website must reflect the identity, energy, purpose, and community-driven nature of ShatterHer.

14. IMPORTANT POINT RULE



Members should NOT automatically receive points simply because they shared a contribution.



The contribution goes through an admin/reviewer approval process.



Flow:



Member shares contribution



↓



Admin/Reviewer reviews



↓



Approved



↓



System calculates points



↓



Points added to member



↓



Leaderboard updates



This prevents fake contributions and leaderboard manipulation.

16. POINT CALCULATION



The system should calculate:



Points = approved quantity × points per unit



Example:



A member shares:



3 poems



Poem = 85 points



Total:



3 × 85 = 255 points



Only approved contributions contribute to the leaderboard.



Admins should be able to override points when necessary.



Every point change must create an audit record.
